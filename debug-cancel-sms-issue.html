🔧 Troubleshooting Steps

Based on our analysis, here are the most likely causes:
  1. iProg API Response Issue: Credits are deducted but SMS delivery fails silently
  2. Phone Number Formatting: Number format might not match iProg requirements
  3. Message Length/Content: Message might be too long or contain invalid characters
  4. Network/Timeout Issues: SMS request times out but credits already deducted
Recommended Actions:
  1. Check server logs during appointment cancellation for error messages
  2. Compare decline SMS vs cancel SMS responses from iProg API
  3. Test with different phone numbers to isolate formatting issues
  4. Monitor network requests to see if SMS API calls complete successfully
  5. Check if there are different iProg rate limits for different message types
