📱 SMS Debug Test - Eye2Wear

This tool helps debug SMS sending issues by testing different scenarios and showing detailed responses.

1. Test SMS Configuration

Tests if the iProg SMS API is properly configured.

2. Test Phone Number Format

Test how phone numbers are formatted for the SMS API.

3. Send Real Test SMS

Send an actual SMS to verify the complete flow.

4. Test Order Completion SMS

Simulate an order completion SMS to debug the specific flow.

5. Check SMS Status

Check the delivery status of a previously sent SMS.
